Try on Wizard Embed Test

This page demonstrates the "Try on Wizard" embed functionality. Click the button below to open this smart contract in the Wizard editor.

Smart Contract Code:

use stylus_sdk::prelude::*; #[entrypoint] fn user_main(input: Vec<u8>) -> ArbResult { // A simple counter contract let mut counter = u64::from_be_bytes([0; 8]); if !input.is_empty() { counter = u64::from_be_bytes(input[..8].try_into().unwrap_or([0; 8])); } counter += 1; Ok(counter.to_be_bytes().to_vec()) }

How it Works:

  1. Embed Generation: The embed code contains the smart contract code, project metadata, and dependencies encoded as base64.
  2. Button Click: When clicked, the button opens a new tab to thewizard.app/tryonwizard/{encodedData}
  3. Authentication: If the user isn't logged in, they'll be prompted to sign in with GitHub.
  4. Project Creation: Once authenticated, a new project is automatically created with the embedded code.
  5. Editor Launch: The user is redirected to the editor with their new project ready to edit and compile.

Note: This test button points to localhost:5173 for development. In production, it would point to thewizard.app.
